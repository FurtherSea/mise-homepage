支持

食序的使用帮助：食材、食谱、餐食计划、采购清单和 iCloud 同步。

报告问题

告诉我们你的 iPhone 型号、iOS 版本和发生了什么，有截图更好。

打开 GitHub Issues

Issue 是公开的，请不要写私人信息。

iCloud 同步

食序通过你自己的 iCloud 私有库同步。另一台设备上没有出现时：

  1. 1打开食序的设置（餐食计划页的齿轮），看 iCloud 同步是否已连接。
  2. 2确认每台设备都打开了 iCloud，登录的是同一个 Apple 账户。
  3. 3稍等一会儿，再关掉并重新打开食序。

开始使用

  1. 1在厨房添加一样食材。
  2. 2新建一个食谱，把食材放进去。
  3. 3把这道菜排进餐食计划。
  4. 4打开采购，查看生成的清单。

数据和隐私

食材、食谱、计划和成品照保存在你的设备和你自己的 iCloud 里。从 1.1 版起，App 还会把使用统计发给 Google Analytics，详见隐私政策。
