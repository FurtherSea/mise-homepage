隐私政策

食序 / Mise 是一款个人厨房和餐食计划 App。这份政策说明 App 保存什么、iCloud 同步怎么工作，以及它发给 Google Analytics 的使用统计里有什么。内容适用于 1.1 及以后的版本；更早的版本不发送使用统计。

  • 没有账号，不用登录
  • 食材、食谱、计划和成品照只在你的设备和你的 iCloud 里
  • 没有服务器，开发者看不到这些内容
  • 没有广告，也没有跨 App 追踪。使用统计发给 Google Analytics，不含菜名、食材名和你输入的文字
App 保存什么 iCloud 同步 成品照和相机 分享清单 使用统计 广告和追踪 来自 Apple 的诊断信息 你的选择 儿童 这个网站 政策变更 联系

App 保存什么

食序里的内容都是你自己填的或选的：食材和它的分类、单位、采购渠道、备注；食谱和它的食材、标签、备注、成品照；餐食计划和里面的菜；还有你的设置。App 自己只多产生一样东西：使用统计。

数据本机你的 iCloudGoogle
食材和采购渠道–没有
食谱、分类和成品照–没有
餐食计划和每道菜–没有
新计划默认天数、每周开始日和引导状态–没有
采购清单的勾选–没有–没有
App 语言和厨房排序–没有–没有
上手引导的进度–没有–没有
使用统计和安装 ID–没有

iCloud 一列只在食序可以使用 iCloud 时生效。Google 一列只在 App 发送使用统计时生效，详见使用统计。和其他 App 的数据一样，iPhone 上的内容可能包含在你自己的设备备份里。

iCloud 同步

如果你登录了 iCloud，食序会通过 Apple 的 CloudKit，把上面的数据同步到你自己 iCloud 账户的私有数据库，这样在其他设备上和重新安装后数据都还在。这些数据占用你的 iCloud 空间。

开发者读不到这个数据库，食序也没有自己的云服务。Apple 按它自己的条款和隐私政策保存这些数据。

成品照和相机

你可以给食谱加一张成品照。只有在你点「拍照」时才会打开相机，第一次使用时 iOS 会询问权限。「从相册选」使用 Apple 的照片选择器，食序只拿到你选中的那张，碰不到相册里的其他照片。

食序只保留你裁出的方形部分，最宽 600 像素，另存为一张新的 JPEG，不带原照片的位置和其他元数据。它和食谱保存在一起，也一样会同步。

分享清单

采购页的「分享清单」会把清单文字交给 iOS 的分享面板，只发给你选的对象。

使用统计

从 1.1 版起，食序使用 Google 的 Google Analytics for Firebase，统计每天和每月的活跃安装数，以及每个功能的使用次数。开发者只用这些数字决定接下来改进什么，不做别的用途。Google 的这个 SDK 是 App 里唯一的第三方 SDK。

App 上报什么。只有下面这些动作，有的带固定选项或小数字：

  • 打开了哪个标签页
  • 看完或跳过介绍页和上手引导，以及完成了引导的第几步
  • 新建食谱，给食谱加成品照
  • 新增食材，以及是在厨房里加的，还是给食谱添加食材时加的
  • 新建计划，以及它的天数
  • 把菜加入一餐，以及哪一餐、几道菜，是从选菜页还是「加入计划」加的
  • 标记一道菜完成，勾选采购项，点「分享清单」，切换清单的分组方式
  • 切换到食谱库的色盘或日历的月视图
  • 用「转一转」或开始搜索，以及在哪个页面

Google 的 SDK 还会自动记录：第一次打开 App、每次使用的开始和时长、App 和 iOS 的更新，以及设备型号、iOS 版本、App 版本、系统语言、安装来源和你的大致位置（城市、地区和国家）。大致位置是 Google 根据 IP 地址估算的，Google 称 Google Analytics 不记录也不保存 IP 地址本身。食序不使用定位服务。

绝不发送什么。菜名、食材名、店名、数量、备注、照片，以及你输入的任何文字，包括搜索内容。食序没有账号，所以也没有姓名、邮箱或 Apple ID 可发。

标识符。SDK 使用两个随机 ID：App Instance ID 和 Firebase Installation ID，每次安装各有一个，删除 App 后都会重置。食序没有账号，所以统计的是安装数，不是人数：两台设备算两个。

发给谁、保存多久。这些数据发到 Google 的服务器，服务器可能不在你所在的国家或地区。Google 是唯一收到这些数据的第三方，它按照 Google Analytics 条款和 Google 隐私权政策处理这些数据，保护水平与本政策相同。更多说明见Google 如何利用从使用 Google 服务的网站和应用中收集的信息。开发者已关闭相关设置，Google 不能用这些数据改进自己的产品，也不能把它们计入行业基准。

开发者看到的是报告，既有总数，也有每个安装 ID 的活动，但里面没有能说明你是谁的信息。Google Analytics 设置为：和安装 ID 关联的数据，最多保留到这次安装最后一次使用后约 14 个月；标准报告里的总数不受这个设置影响，可能保存更久。

不发送的地区。如果你的 App Store 国家或地区属于欧洲经济区、英国、瑞士或中国大陆，App 不会启动这个 SDK，什么都不发送。App 读不到商店信息的那次启动也一样。

能不能关闭。App 里没有关闭这项统计的设置。要停止，只能删除 App。

广告和追踪

食序不显示广告，也不出售你的数据。它不会跨其他公司的 App 或网站追踪你，所以不会弹出 Apple 的「App 跟踪透明度」询问。这个 Google SDK 的广告功能都已关闭：不存储广告数据，不做广告个性化，也不向 Apple 的广告归因注册。食序不收集 Apple 的广告标识符（IDFA）和供应商标识符（IDFV）。

来自 Apple 的诊断信息

如果你在设备设置里选择了与 App 开发者共享分析数据，Apple 可能通过开发者工具提供崩溃报告和使用统计，用来修复问题、提高稳定性。App Store Connect 还会向开发者显示下载量和使用次数这类总体数字。

这个设置只管 Apple 收集的内容，不影响上面说的 Google Analytics 使用统计。崩溃报告只来自 Apple。

你的选择

你可以随时在 App 里修改食材、食谱和计划，也可以删除食材、食谱和今天及以后的计划。

有两样内容会特意保留，让历史记录完整：过去的餐食不能删除，只能标记完成或取消完成；被过去餐食用过的食谱，删除后只是从食谱库隐藏，不会抹掉。

想删除全部内容：打开食序的设置，点「删除所有数据」。这会清空这台设备和 iCloud 里的食材、食谱和计划，登录同一个 iCloud 的其他设备也会清空。只删除 App 只会清除这台 iPhone 上的数据，iCloud 里的内容在重新安装后还会回来。只想停止同步的话，在系统设置里关掉食序的 iCloud。

「删除所有数据」还会重置这台设备上的 App Instance ID，之后 App 算作新的安装。已经发出的使用统计不会因此删除，它们按上面写的时间过期。食序没有账号，App 也不显示这些 ID，所以开发者分不出哪些统计是你的，也没办法替你查找。

儿童

食序是一款通用的烹饪和餐食计划 App，不面向儿童，也不会有意收集儿童的个人信息。

这个网站

这个网站不使用 Cookie、统计或广告，字体也从网站自身加载。它只在你的浏览器里记住你选的语言。网站托管在 GitHub Pages 上，GitHub 会出于安全目的记录访问者的 IP 地址，详见 GitHub 隐私声明。

政策变更

食序处理数据的方式改变时，这份政策也会改。如果以后的版本发送新的数据，或者加入广告、账号或联网功能，这里会在那个版本发布之前写明，并更新顶部的日期。
